## Health Class Entry Schema

[[edit source](/w/Module:DamageTypes/data/doc?action=edit&section=1 "Edit section's source code: Health Class Entry Schema")]

```lua
		["Health Class"] = {
			Bypass = {  },
			CSSTextColorClass = "var(--css-var-name)",
			Faction = { "Grineer", "Corpus", "Infested" },
			InternalName = "",
			Link = "Page name",
            Name = "Health Class",
			Negatives = { { "Slash", 50 }, { "Magnetic", 50 }, { "Electricity", 50 } },
			Nickname = "Nickname",
			Positives = { { "Cold", 25 }, { "Puncture", 15 }, { "Radiation", 75 } },
			Type = "Armor, Health, or Shield" 
		},
```

| Key/Column Name | Data Type | Required? | Explanation/Description | Example(s) |
| --- | --- | --- | --- | --- |
| `Bypass` | Table (of 2-element tables) | ✔️ | Damage types that ignore this health class | `{ { "True", 0 } }` or `{ }` |
| `Color` | String | ❌ | Depreciated as of 2025-03-16, use `CSSTextColorClass` instead. Default HSL color value (hue, saturation) | `"250, 10%"` |
| `CSSTextColorClass` | String | ✔️ | The name of the CSS variable in [MediaWiki:Common.css](/w/MediaWiki:Common.css "MediaWiki:Common.css") for text color | `var(--faction-tenno-text-color)` |
| `DarkModeColor` | String | ❌ | Depreciated as of 2025-03-16, use `CSSTextColorClass` instead. Dark mode HSL color value (hue, saturation) | `"250, 10%"` |
| `Faction` | Table (of strings) | ✔️ | Name of enemy factions that use this health class | `{ "Grineer", "Infested" }` |
| `InternalName` | String | ✔️ | The internal name/code name | `"RK_HULKING_ARMOR"` |
| `Link` | String | ✔️ | Page/article link to the weapon on the wiki | `"Infested (Health)"` |
| `Name` | String | ✔️ | Name of health class | `"Infested"` |
| `Negatives` | Table (of 2-element tables) | ✔️ | Damage types that have a negative [Damage Type Modifier](/w/Damage_Type_Modifier "Damage Type Modifier") against this health class | `{ { "Slash", 50 }, { "Magnetic", 50 } }` or `{ }` |
| `Nickname` | String | ✔️ | Short name for health class | `"Ferrite"` |
| `Positives` | Table (of 2-element tables) | ✔️ | Damage types that have a positive [Damage Type Modifier](/w/Damage_Type_Modifier "Damage Type Modifier") against this health class | `{ { "Cold", 25 }, { "Puncture", 15 } }` or `{ }` |
| `Type` | String | ✔️ | Type of health class ("Armor", "Health", or "Shield") | `"Shield"` |

## Status Effect Entry Schema

[[edit source](/w/Module:DamageTypes/data/doc?action=edit&section=2 "Edit section's source code: Status Effect Entry Schema")]

```lua
		["Status Effect"] = {
			CSSBackgroundColorClass = "var(--css-var-name)",
			CSSBorderColorClass = "var(--css-var-name)",
			CSSTextColorClass = "var(--css-var-name)",
			GlyphImage = "Glyph .png image name",
			Icon = "64px .png icon name",
			InternalName = "",
			Link = "Page name",
			Name = "Name",
			Status = { "Stagger" },
			StatusNotes = { 1, 2 } 
		},
```

| Key/Column Name | Data Type | Required? | Explanation/Description | Example(s) |
| --- | --- | --- | --- | --- |
| `Bypass` | Table (of strings) | ❌ | For Toxin procs, the health classes that are ignored by this status effect's DoT | `{ "Shield", "Proto Shield", "Tenno Shield" }` |
| `BypassNotes` | Table (of ints) | ❌ | For non-empty Bypass key, indices of additional notes as stored in `Notes` subtable | `{ 5 }` |
| `Color` | String | ❌ | Depreciated as of 2025-03-16, use `CSSTextColorClass` instead. Default color hex code associated with damage/status type | `"#3d5e5e"` |
| `ColorBackground` | String | ❌ | Depreciated as of 2025-03-16, use `CSSBackgroundColorClass` instead. Color hex code associated with damage/status type; for use on damage tooltips ([Template:D](/w/Template:D "Template:D")) | `"#cad8d8"` |
| `ColorBorder` | String | ❌ | Depreciated as of 2025-03-16, use `CSSBorderColorClass` instead. Color hex code associated with damage/status type; for use on damage tooltips ([Template:D](/w/Template:D "Template:D")) | `"#486061"` |
| `CSSBackgroundColorClass` | String | ✔️ | The name of the CSS variable in [MediaWiki:Common.css](/w/MediaWiki:Common.css "MediaWiki:Common.css") for background color | `var(--dt-impact-background-color)` |
| `CSSBorderColorClass` | String | ✔️ | The name of the CSS variable in [MediaWiki:Common.css](/w/MediaWiki:Common.css "MediaWiki:Common.css") for border color | `var(--dt-impact-border-color)` |
| `CSSTextColorClass` | String | ✔️ | The name of the CSS variable in [MediaWiki:Common.css](/w/MediaWiki:Common.css "MediaWiki:Common.css") for text color | `var(--dt-impact-text-color)` |
| `DarkModeColor` | String | ❌ | Depreciated as of 2025-03-16, use `CSSTextColorClass` instead. Color hex code associated with damage/status type for dark mode | `"#80c4c4"` |
| `GlyphImage` | String | ❌ | Image file name of the damage [Glyph](/w/Glyph "Glyph") as uploaded to the wiki | `"EssentialImpactGlyph.png"` |
| `Icon` | String | ✔️ | Image file name of the 64px damage icon as uploaded to the wiki | `"DmgImpactSmall64.png"` |
| `InternalName` | String | ✔️ | The internal name/code name | `"PT_FLASHBANG"` |
| `Link` | String | ✔️ | Page/article link to the status effect on the wiki | `"Damage/Viral Damage"` |
| `Name` | String | ✔️ | Name of status effect | `"Bleeding"` |
| `Status` | Table (of strings) | ✔️ | Description of effects that occur from the proccing its [Status Effect](/w/Status_Effect "Status Effect") | `{ "Tesla Chain", "Stun" }` or `{ }` |
| `StatusNotes` | Table (of ints) | ✔️ | Indices of additional notes as stored in `Notes` subtable | `{ 1, 2 }` or `{ }` |
