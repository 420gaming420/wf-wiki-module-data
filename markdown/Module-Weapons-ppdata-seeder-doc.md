## Schema

[[edit source](/w/Module:Weapons/ppdata/seeder/doc?action=edit&section=1 "Edit section's source code: Schema")]

Resultant table generated by `p.ppData(frame)` will have the following schema:

```lua
			{	Type = 'Bows',
				Classes = { 'Bow', 'Crossbow', 'Exalted Weapon' },
				Triggers = {
					{	Name = 'Auto',
						{'Auto'},
						Weapons = {},
					},
					{	Name = 'Charge',
						{'Charge'},
						Weapons = {},
					},
					{	Name = 'Hybrid',
						{'Semi / Burst'},
						Weapons = {},
					},
				},
			},
```

Each table entry is indexed by position.

| Key/Column Name | Data Type | Required? | Explanation/Description | Example(s) |
| --- | --- | --- | --- | --- |
| `Type` | String | ✔️ | Weapon type in plural form to be displayed as a wikitable header row on [Template:WeaponNav](/w/Template:WeaponNav "Template:WeaponNav") | `"Rifles"` |
| `Classes` | Table (of strings) | ✔️ | Name of [Module:Weapons/data](/w/Module:Weapons/data "Module:Weapons/data") `Class` key values of weapons beneath the `Type` header row | `{ "Exalted Weapon" }` |
| `Triggers` | Table (of tables) | ✔️ | Contains definitions of wikitable rows beneath the Type header row on [Template:WeaponNav](/w/Template:WeaponNav "Template:WeaponNav").  * `Name` key represents wikitable row name * `[2]` is a table that contains either   + For guns, [Module:Weapons/data](/w/Module:Weapons/data "Module:Weapons/data") `Trigger` key values of weapons that will be shown for that row   + For melees, [Module:Weapons/data](/w/Module:Weapons/data "Module:Weapons/data") `Class` key values of weapons that will be shown for that row * `Weapons` table contains all the weapon names that will be shown for that row | `{ Name = "Charge", { "Charge" }, Weapons = {} }` |

### Table Definition

[[edit source](/w/Module:Weapons/ppdata/seeder/doc?action=edit&section=3 "Edit section's source code: Table Definition")]

If using the following table definition to build a single "Primary" weapon tab of [Template:WeaponNav](/w/Template:WeaponNav "Template:WeaponNav") in [Module:Weapons/nav](/w/Module:Weapons/nav "Module:Weapons/nav").

```lua
		Primary = {
			{	Type = "Arm Cannons",
				Classes = { "Arm Cannon" },
				Triggers = {
					{	Name = "Auto",
						{ "Auto" },
						Weapons = { "Bubonico", "Shedu" },
					},
				},
			},
			{	Type = "Assault Rifles",
				Classes = { "Rifle" },
				Triggers = {
					{	Name = "Active",
						{ "Active" },
						Weapons = { "Simulor", "Synoid Simulor" },
					},
					{	Name = "Auto",
						{ "Auto" },
						Weapons = { "Acceltra", "Basmu", "Baza", "Baza Prime", "Boltor", "Boltor Prime", "Telos Boltor" },
					},
					{	Name = "Auto-Burst",
						{ "Auto Burst" },
						Weapons = { "Battacor" },
					},
					{	Name = "Auto-Spool",
						{ "Auto-Spool" },
						Weapons = { "Gorgon", "Prisma Gorgon", "Gorgon Wraith", "Soma", "Soma Prime", "Supra", "Supra Vandal" },
					},
					{	Name = "Burst",
						{ "Burst" },
						Weapons = { "Burston", "Burston Prime", "Harpak", "Hema" },
					},
					{	Name = "Charge",
						{ "Charge" },
						Weapons = { "Miter", "Opticor", "Opticor Vandal" },
					}
				},
			},
```
