This is the documentation page for Module:Cosmetics/userdata

Users collection maps items to the cosmetics they can equip in the respective cosmetic slot.

Cosmetic items in this collection should have a corresponding entry on a Module:Cosmetics/data subpage.

Users Data Schema

[edit]
		["Item Name"] = {
			Equipments = {
				["Animation Set"] = {
					"Animation Set Name",
				},
				Auxiliary = {
					"Auxiliary Name",
				},
				Armor = {
					"Armor Name",
				},
				Emblem = {
					"Emblem Name",
				},
				Ephemera = {
					"Ephemera Name",
				},
				Helmet = {
					"Helmet Name",
				},
				Holster = {
					"Holster Name",
				},
				Livery = {
					"Livery Name",
				},
				Skin = {
					"Skin Name",
				},
			},
			Type = "Weapon/Warframe/Attachment/Vehicle/Companion",
		},
