This is the documentation page for Module:Tooltips/tip


Tooltips/tip builds the tooltip box of a tooltip. CSS stylesheet for tooltips can be found on MediaWiki:Gadget-Tooltips.css.

Submodule of Module:Tooltips. Not meant to be invoked by itself, see the main module page for usage.
