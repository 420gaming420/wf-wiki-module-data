# Attribution

This repository contains data converted from the [WARFRAME Wiki](https://wiki.warframe.com) Lua modules.

## Source Information

### Primary Source
- **Wiki**: WARFRAME Wiki
- **URL**: https://wiki.warframe.com
- **Module pages**: Module URL's in their _attribution JSON key.
- **License**: CC BY-NC-SA 3.0 (for content created after January 31, 2025)
- **Previous license**: CC BY-SA 3.0 (for content created before January 31, 2025)

### Conversion Details
- **Converter tool**: https://github.com/420gaming420/wf-wiki-module-scripts
- **Conversion method**: Automated parsing and execution of Lua modules
- **Data format**: JSON (structured data extracted from Lua tables)

## Attribution Requirements

When using data from this repository, you must provide the following attribution:

### 1. Source Credit
```

```


## Meta Files

Each JSON data file includes a corresponding `.meta.json` file with:
- Source module page URL
- Conversion timestamp
- Output file name
- File size
- Conversion status

Example:
```json
{
  "page": "Module:Warframes/data",
  "converted_at": "2026-08-29T15:45:36.555Z",
  "output_file": "Module-Warframes-data.json",
  "file_size": 194638,
  "status": "success"
}
```
